# Component Context MCP

MCP-сервер, который даёт AI-ассистенту проверенный контекст о React-компонентах: доступные компоненты, prop API, правила использования и рабочие примеры. Прототип решает типичную проблему AI-разработки: модель перестаёт придумывать несуществующие пропсы и получает документацию в компактном формате по запросу.

## Что умеет

- `list_components` — список компонентов дизайн-системы;
- `search_components` — поиск по названию, назначению, тегам, пропсам и правилам;
- `get_component_context` — готовый для контекстного окна документ с API, ограничениями и TSX-примерами;
- понятная ошибка и подсказка, если компонент не найден.

## Стек

TypeScript, Node.js, Model Context Protocol SDK, Zod, Node Test Runner.

## Запуск

```bash
npm ci
npm run build
npm test
node dist/index.js
```

Конфигурация для MCP-клиента:

```json
{
  "mcpServers": {
    "component-context": {
      "command": "node",
      "args": ["/absolute/path/to/component-context-mcp/dist/index.js"]
    }
  }
}
```

## Архитектура

Каталог компонентов хранит структурированные сведения о prop API, правилах и примерах. Поиск ранжирует результаты по совпадениям во всех полях. MCP-слой раскрывает каталог через три небольших инструмента, поэтому в контекст модели попадает только нужная информация.

Для production-версии каталог можно автоматически собирать из TypeScript-типов, Storybook и Figma API, версионировать и публиковать в CI/CD. Следующие шаги: AST-индексация исходного кода, embeddings для семантического поиска, кэширование и проверка актуальности документации по commit SHA.

## Почему проект сделан

Проект показывает практический подход к AI-инфраструктуре frontend-команды: модель получает реальные API компонентов и правила проекта вместо общего контекста. Архитектура намеренно компактная, чтобы её можно было быстро подключить к реальной библиотеке компонентов.
